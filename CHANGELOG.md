# Changelog

## 1.0.0 (unreleased)

Initial experimental release.

- Offline MSG and EML conversion, message preview and attachment extraction.
- Desktop workbench with batch queues, cancellation, local activity and JSON reports.
- Terminal launcher using the packaged runtime and shared conversion engine.
- Optional LibreOffice integration with platform-specific process isolation.
- Graphite glass interface with bundled Poppins typography.
- Native installer configurations for macOS, Windows and Linux.
- Apache-2.0 licensing with bundled third-party notices.

The tool is experimental and comes with no warranty of any kind. See the README and security documentation for limitations.
