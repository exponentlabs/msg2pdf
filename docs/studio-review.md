# PR #10 ADR and B1–B8 review

Reviewed 9 November 2026 against ADRs 0001–0009 and the original B1–B8 exit criteria. Scope remains the initial bounded Fedora 44 ARM64 raster profile. Validation runs locally; no workflow dispatch or main-target PR is needed.

## Findings and fixes

| Priority | Gap                                                                                                                                                        | Resolution and regression evidence                                                                                                                                                                                                                                                                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1       | Deleting live lock metadata admitted a second owner through a new inode (ADR 0002/B3).                                                                     | Retain the persistent-file flock and add an independent root-directory flock, both close-on-exec. Check held/root/file identities before writes. Native tests delete the metadata while an owner is alive; the second opener gets `CASE_BUSY`, and the original owner blocks changed-path writes. Packaged tests exercise the directory guard and CLI error code using the shipped runtime/addon. |
| P1       | Capturing a FIFO could wait indefinitely before the regular-file check (B3/B8 resource bounds).                                                            | Open intake with `O_NONBLOCK` and `O_NOFOLLOW`, then require a bounded regular file. A real FIFO regression rejects without a writer or committed source.                                                                                                                                                                                                                                         |
| P1       | Separator-only phrase searches could repeatedly scan all fragments without hitting the result cap (B5/B8).                                                 | Reject whitespace-only phrases, cap occurrences independently of returned regions, traverse fragment spans monotonically, and deduplicate matching line regions. Tests include 50,000 fragments, cross-fragment phrases and repeated matches.                                                                                                                                                     |
| P1       | Earlier prepared inventories could survive the source-inventory fixes if only their candidate PDF was regenerated (B5/B7).                                 | Introduce studio policy v2. Earlier development cases retain read/backup access, but processing and approval require fresh capture and review. Packaged CLI tests exercise stale-policy rejection and backup access without migrating approvals.                                                                                                                                                  |
| P2       | Release records retained a context hash but no readable frozen family decisions (ADR 0005/B6).                                                             | New approvals retain a deep copy of the selected families/dispositions; history shows the approved reasons even after later edits. The gate checks the snapshot against the approved selection. Earlier records are explicitly shown without invented history. Public manifests include only neutral fields and the mandatory non-sensitive check outcomes.                                       |
| P2       | Unreadable attachments were reduced to an incomplete-inventory flag, losing their names/identities (ADR 0005/B7).                                          | Retain opaque identities, private names and extraction failure codes without fabricating source hashes. These items remain unresolved and block their affected family. Real PDF inventory tests include an external/unreadable file specification.                                                                                                                                                |
| P2       | Signed MSG normalization dropped its outer signature wrapper (ADR 0005/B7).                                                                                | Retain the hidden wrapper and other outer items alongside normalized MIME attachments. A regression checks the exact retained wrapper bytes. Legacy ordinary attachment exports continue to omit signature material.                                                                                                                                                                              |
| P2       | Office scratch lived outside recorded case recovery (ADR 0006/B7–B8).                                                                                      | Put it in a declared private case job tree and expose only that subtree at `/work` inside bubblewrap. The short mount avoids Unix socket path limits. Close/cancellation/reopen clean bounded owned profile/cache/output data; unexpected root files, symlinks and aliases block cleanup. Real isolated LibreOffice and tracked-tree restart tests pass.                                          |
| P2       | Case creation/backup could enter another managed case and change permissions on a rejected nonempty folder (ADR 0002/B3).                                  | Check managed ancestry and empty ownership before chmod or case metadata writes. Tests cover nested destinations, aliased ancestry and preserved permissions.                                                                                                                                                                                                                                     |
| P2       | Native lock codes were lost through Electron's message-only errors; CLI failures lacked stable codes (ADR 0006/B2/B7).                                     | Normalize native/domain failures once, preserve the code in GUI messages, and emit the same code in CLI JSON.                                                                                                                                                                                                                                                                                     |
| P2       | Stage counts were not queues, blockers were hidden, and the approval button used the current document instead of the actual selected subset (ADR 0003/B7). | Add captured/review queue filters and visible per-document blockers; evaluate the selected IDs for button availability and clear selections on case switches.                                                                                                                                                                                                                                     |
| P2       | The native GUI tests did not prove canonical drag geometry on cropped/rotated mixed-size pages at multiple zooms (B4/B8).                                  | A real Electron test marks the same known image region at 50% and 100%, checks saved canonical coordinates, reviews both differently sized pages, and independently verifies the generated candidate.                                                                                                                                                                                             |
| P2       | Verifier unavailability prevented opening/backing up existing private cases (B3/B8).                                                                       | Separate case access from processing availability. Opening and backup use the qualified store/lock adapter; candidate generation/review/publication still require the full current verification pipeline.                                                                                                                                                                                         |
